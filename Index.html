Masterlist

Rate card values for each km bracket, by one-way distance to the destination. The variable rate and fuel efficiency set the client's billed rate. Fuel efficiency also sets the internal fuel cost over the round trip; maintenance is set in Settings. Trips within the first 15 km use the first bracket. Add, remove or change brackets here; saving writes them to the Masterlist sheet.
